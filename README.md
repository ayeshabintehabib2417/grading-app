# 📘 Grading System - MERN Stack Project

This is a full-stack web application for managing a grading system. Built using **MongoDB**, **Express**, **React**, and **Node.js** – the MERN stack. It allows **admins (teachers)** to manage student records and **students** to view their grades and information.

---

## 🚀 Features

- 🔐 Login system for Admin and Students
- 📋 Admin Dashboard to:
  - Add new students
  - Update student details
  - View all student records
- 📄 Student Portal to:
  - View personal records
- 🌐 REST API integration with MongoDB using Express
- 🗃️ MongoDB Compass used as GUI for managing the database

---

## 🛠️ Technologies Used

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB + Mongoose
- **Styling:** CSS
- **Tooling:** MongoDB Compass, VS Code
